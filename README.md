# 🛡️ ሻህ ባህል ስፖርት — ይፋዊ የግላዊነት ፖሊሲ መድረክ (Official Privacy Policy Portal)

###  ስለ ተቋሙ
የኢትዮጵያ ባህል ስፖርቶች ፌዴሬሽን የባህል ስፖርቶቻችንን በመላ ሀገሪቱ ለማጥናት፣ ለመጠበቅ፣ ለማስፋፋት፣ ለማስተዋወቅ፣ ለማልማት እንዲሁም ለመምራት ከኢ.ፌ.ዲ.ሪ ባህልና ስፖርት ሚኒስቴር ፈቃድ ተሰጥቶት በ1970 ዓ.ም የተመሰረተ አንጋፋ ተቋም ነው፡፡

### 🔒 የውሂብ ደህንነት ማረጋገጫ
* መተግበሪያው **100% ከመስመር ውጭ (Offline)** የሚሰራ ሲሆን ከተጠቃሚዎች ምንም ዓይነት የግል መለያ መረጃ አይሰበስብም፣ አይሸጥም ወይም ለሦስተኛ ወገን አያጋራም።
* ለሁሉም የዕድሜ ክልል (ህፃናትንና ቤተሰብን ጨምሮ) ደህንነቱ የተጠበቀ ባህላዊ ስፖርት ነው።
