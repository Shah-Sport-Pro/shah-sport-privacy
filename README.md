​🏛️ ስለ ተቋሙ
​የኢትዮጵያ ባህል ስፖርቶች ፌዴሬሽን የባህል ስፖርቶቻችንን በመላ ሀገሪቱ ለማጥናት፣ ለመጠበቅ፣ ለማስፋፋት፣ ለማስተዋወቅ፣ ለማልማት እንዲሁም ለመምራት ከኢ.ፌ.ዲ.ሪ ባህልና ስፖርት ሚኒስቴር ፈቃድ ተሰጥቶት በ1970 ዓ.ም የተመሰረተ አንጋፋ ተቋም ነው፡፡
​ራዕይ፦ ህዝባዊ መሰረት ያለው የባህል ስፖርት ተሳትፎን በማጎልበት እና በማስፋፋት በአለም አቀፍ ደረጃ የሀገራችን የባህል ስፖርቶች ታዋቂነት አግኝተው ማየት እና ተደራሽነታቸውን ማሳደግ ላይ ራዕዩን ያደረገ ሀገር በቀል ተቋም ነው።
​ተልዕኮ፦ የባህል ስፖርቶችን በተለያዩ የህብረተሰብ ክፍሎች ዘንድ ተዘውታሪ እንዲሆኑ እና በአለም አቀፍ ደረጃ እንዲታወቁ እንዲሁም እንዲዘወተሩ ማድረግ የሚል ተልዕኮን አንግቦ የተነሳ ተቋም ነው፡፡
​እሴቶች፦ ውጤታማነት፤ ግልፀኝነት እና ተጠያቂነት፤ ቁርጠኝነት፤ የቡድን ስራ፤ ልቆ መገኘት፤ ጥራት ዋና ዋናዎቹ ናቸው ፡፡
​🔒 የ«ሻህ» v1.0.0 የግላዊነትና ደህንነት ማረጋገጫ
​ምንም የግል መረጃ አይሰበሰብም፦ የ«ሻህ» v1.0.0 መተግበሪያ ከተጠቃሚዎች ምንም ዓይነት የግል መለያ መረጃ (ስም፣ ስልክ ቁጥር፣ ፎቶ ወይም መገኛ ቦታ) አይሰበስብም።
​100% ከመስመር ውጭ (Offline)፦ መተግበሪያው ያለ ኢንተርኔት ግንኙነት የሚሰራ ሲሆን የተጠቃሚዎችን መረጃ ለማንኛውም ሦስተኛ ወገን አያጋራም።
​ለሁሉም የዕድሜ ክልል ደህንነቱ የተጠበቀ፦ ትምህርታዊ፣ ስፖርታዊና ባህላዊ ይዘት ያለው ለህፃናትና ለቤተሰብ 100% ተስማሚ መተግበሪያ ነው።
